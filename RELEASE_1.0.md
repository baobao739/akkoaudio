# 🎧 AkkoAudio 1.0

**The first official AkkoAudio release.**

AkkoAudio 1.0 brings together the music player, queue system, synchronized lyrics, Focus Mode, personalization, responsive UI, and the growing built-in music library into one polished experience.

## ✨ Features

### 🎵 Music Player
- Built-in audio playback with play/pause controls.
- Previous / next song controls.
- Seek/progress bar and playback time display.
- Volume controls.
- Mini player for quick playback control.
- Full player view for a larger now-playing experience.
- Album artwork, song title, artist, and album information.
- Smooth animated playback UI.

### 📋 Up Next Queue
- Dedicated **Up Next** queue.
- Queue represents upcoming songs rather than the currently playing song.
- Add songs to the queue from the music library.
- Queued songs play after the current song finishes.
- Finished queued songs are removed from Up Next as playback advances.
- Queue playback and navigation are handled by the main player.

### 🎤 Lyrics
- LRC-based synchronized lyrics.
- Active-line lyric highlighting.
- Smooth lyric movement/animation.
- Full-player lyric display.
- Lyrics are included for supported songs in the music library.
- Explicit-language censoring is supported in lyric files where applicable.

### 🌌 Focus Mode
- Dedicated full-screen listening experience.
- Large artwork and lyrics presentation.
- Dynamic artwork-inspired visual atmosphere.
- Animated background blobs and visual effects.
- Responsive Focus Mode behavior for desktop and mobile.
- Touch-friendly controls.
- Focus Mode keeps player controls interactive while the visual experience is active.

### 🎨 Themes & Personalization
- Multiple app themes.
- Expanded accent-color selection.
- Theme and accent choices are saved for future visits.
- Accent colors are applied throughout the interface.
- Theme-aware glass panels, borders, highlights, and backgrounds.
- Animated accent transitions.

### 🪟 UI / Design
- Vibrant spatial-glass design.
- Glassmorphism panels with blur and depth.
- Animated ambient background lighting.
- Responsive desktop, tablet, and mobile layouts.
- Mobile navigation/player support.
- Smooth hover, tap, focus, and page animations.
- Touch-optimized controls.

### 📱 Mobile Support
- Responsive layout for phones and tablets.
- Mobile-friendly bottom player/navigation.
- Touch interaction improvements for player controls and Focus Mode.
- iPhone-specific Focus Mode lyric/layout fixes.

### 🎶 Music Library
- Built-in local music entries with associated artwork and lyrics.
- Album and artist metadata.
- Growing collection of supported tracks.
- Current library includes tracks such as **Dark Thoughts — Lil Tecca**, with matching audio, cover art, and lyrics assets.

## 🛠️ Polish & Reliability
- Improved audio playback and song navigation.
- Queue behavior refined to preserve upcoming songs correctly.
- Empty-player handling.
- Improved pointer-event handling so controls remain clickable.
- Refined Focus Mode interactions.
- Smoother visual animations using CSS where appropriate.
- Improved mobile touch behavior.

## 📦 Release

**Version:** `1.0.0`  
**Status:** Stable / First official release

AkkoAudio 1.0 is the foundation for future updates, new music, more customization, and additional player features.
